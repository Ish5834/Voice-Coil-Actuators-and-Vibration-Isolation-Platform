This has been the main focus of the project till now. The current models of vibration isolation that exist use the following type of linear actuators:
1. piezoelectric (Nano-precision, high-freq)
2. voice coil (High bandwidth, Low freq)
3. electromagnetic (High force, Heavy loads)
4. pneumatic (Low-freq, Passive/Active)

Based on the requirements of the project and the physical constraints, we chose to go forward with making custom voice coil actuators.
VCAs offer the best combination of bandwidth and precision for the 1–10 Hz target range, while remaining manufacturable in-house
